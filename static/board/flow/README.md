# 발표 시연 (`/flow`)

`/flow` 는 **실제 서비스 화면 + 위에 시연 막대**예요. 따로 만든 가짜 화면이 아니에요 (10/7부터).

- `/flow` 로 들어오면 이 브라우저에 "발표 모드"가 켜지고 실제 방 만들기(`/`)로 가요.
- 발표 모드인 브라우저에서만 화면 위에 막대가 떠요: `시연 [개발자 시점] ⋯`
  - **개발자 시점**: 방 만들기(`/`)로
  - **`⋯` (발표 설정)**: 지금 결과 보기(`?preview=1`) · 다른 폰에서 들어온 것처럼(이 방 참여 기억 지우기) · 처음부터 다시 · 발표 모드 끄기
- 시연 중 만든 방 링크는 **진짜 링크(`/r/{code}`)** 예요. 단톡방 · 관객 폰에서 열면 막대 없는 실제 서비스로 열리고 같은 방에 참여돼요.
- 막대 코드: `demo-bar.js`. 실제 화면(`static/rooms/index.html` · `room.html` · `static/expenses/add.html` · `static/board/board.html`)에 스크립트 한 줄씩만 있어요. 발표 모드가 아니면 아무것도 안 해요.
- 예전 가짜 주소(`/flow/r/{code}`, `/me`, `/board`)는 실제 주소로 넘어가요.

## 시연 순서 (예)
1. `/flow` → 방 만들기 (거래를 많이 보여 주려면 시작일을 10/2 로: 가짜 은행 거래가 10/2 ~ 10/7)
2. 링크 복사 → 단톡방 · 관객에게 보내기 (관객도 실제로 참여)
3. 은행 연결하고 참여하기 → 가짜 은행 동의 → 계좌 선택 → 내 기록
4. 불러오기 → 1/N · 제외 → 조정 완료
5. `⋯` → 지금 결과 보기 (마감 전에도 결과 카드, 자동 반영 포함)

## 주의
- 실제 DB를 써요. 발표장에 인터넷이 필요하고, 만든 방은 마감 30일 뒤 자동으로 지워져요.
- 서버(Render 무료)가 잠들어 있으면 첫 접속에 1분쯤 걸려요. 발표 전에 한 번 열어 두세요.
- 개인정보 처리방침은 `/flow/privacy` (모든 화면 바닥글).
