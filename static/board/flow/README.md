# 시연용 전체 흐름 (`/flow`)

보드 레인(김경은)이 만든 **화면 전체 시안이자 시연용 흐름**이에요. 다른 레인의 기능이 아직 없어도 발표 시연이 끊기지 않게 만들었어요.

| 주소 | 화면 | 실제로 옮길 곳 (담당) |
|---|---|---|
| `/flow` | 방 만들기 | `/` · `static/rooms/index.html` (안정훈) |
| `/flow/r/{code}` | 방 홈 · 참여: 닉네임 · 예산 · **숫자 4자리** → 은행 연결 동의 → 계좌 불러오는 중 → 계좌 고르기 (실제 오픈뱅킹 순서). 이미 참여한 브라우저면 바로 내 기록으로. 다른 브라우저면 **이미 참여했어요 → 내 이름 → 4자리** | `/r/{code}` · `static/rooms/room.html` (안정훈) + 등록계좌조회 API (이태윤) + **4자리 저장 · 다시 들어오기 API (안정훈)** |
| `/flow/r/{code}/me` | 내 페이지 (불러오기 · 1/N · 제외 · 조정 완료 · 항복) | `/r/{code}/add` · `static/expenses/add.html` (이태윤) |
| `/flow/r/{code}/board` | 마감일 결과 카드 (마감 전엔 D-day · 빈 메달 자리) | 이미 실제 화면 `/r/{code}/board` 와 같은 코드 (김경은) |

- 참여한 뒤에는 화면 아래 **고정 탭 [내 기록 | 결과]** 으로만 오가요 (`Flow.tabbar`).
- 숫자 4자리는 회원가입이 아니에요: 연락처 · 실명 없이 그 방 안에서만 쓰고, 실제 서비스는 서버에서 해시(hashlib)해 `members` 에 저장해요. 5번 틀리면 30초 잠금.
- 데이터는 **이 브라우저의 localStorage에만** 저장하는 가짜 데이터예요. 서버와 DB를 쓰지 않아요. 그래서 QR로 들어온 다른 사람 휴대폰과는 공유되지 않아요 (관객 참여는 실제 방 화면으로).
- `/flow/r/demo` 는 `db/seed.sql` 데모 방과 같은 구성(발표자 계좌 A · 짠돌이 · 카페중독 · 큰손 · 포기각)으로 시작해요.
- 거래는 가짜 은행(`app/expenses/mockbank/data.py`)과 같은 데이터, 결과 계산은 `app/board/calc.py` 와 같은 규칙이에요.
- 영수증 위 **시연 막대** (10/3 회의의 "버튼 두 개"): 발표하는 사람만 쓰고, 각 레인으로 옮길 때는 가져가지 않아요.
  - **참여자 시점**: 데모방에 계좌 A 로 참여한 발표자가 되어 내 페이지부터 → 불러오기 → 1/N · 제외 → 조정 완료 → 결과 카드 (날짜는 발표날 10/8)
  - **개발자 시점**: 방 만들기부터 → 링크 → 닉네임 → 은행 연결 → 계좌 선택 → 내 페이지 → `⋯` 의 가상 참여자 채우기 · 마감일 → 결과 카드
  - **`⋯` 도구**: 오늘 날짜(진짜 오늘 / 마감일) · 결과 카드 보기 · 가상 참여자 채우기 · 데모 방 열기 · 처음부터 다시

## 자기 레인으로 옮기는 법
1. 이 폴더의 HTML 구조와 `flow.css` 의 해당 부분, `../common-proposal.css` 클래스(`.pick` `.tag` `.danger-line` 등)를 가져가요.
2. `store.js` 맨 위 "바꿔 끼우는 자리" 표대로, 가짜 함수 대신 실제 API를 불러요.
3. 기능이 빠지거나 바뀌면 그 부분 화면만 빼면 돼요.
