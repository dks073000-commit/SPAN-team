텅장방어전 UI 가이드

모든 화면은 회색 계산대 위에 놓인 흰 영수증 한 장이에요. 실제로 눌러 보는 전체 흐름은 /flow 에 있어요.

10/4 기준. 서비스 이름 "텅장방어전"(로고는 투표 전이라 A안 임시) · 미제출 대신 미확인 · 항복 · 기간 중 순위 없음(마감일 결과 카드) · 참여할 때 은행 연결 → 계좌 선택 · 1 · 2 · 3등 메달.

다섯 가지 규칙

  1. 한 화면은 영수증 한 장, 큰 글자 하나 + 기본 버튼 하나. 설명 문장은 쓰지 않고 점선으로 구획을 나눠요.
  2. 형광펜은 "나"에게만. 69,000원 처럼 내 숫자와 내 줄에만 칠해요.
  3. 상태는 도장, 사람은 색. 초과 · 완주 · 미확인 · 항복은 글자 도장으로, 사람마다 정해진 색은 "누구인지"에만 써요.
  4. 글꼴은 하나. Noto Sans KR 로 글과 숫자를 모두 쓰고, 금액과 % 는 .n 으로 감싸 자리를 맞춰요.
  5. 말투는 해요체, 숫자 먼저. 초과하거나 항복한 친구를 놀리지 않고 다시 버틸 이유를 줘요.

색

  • 계산대 --counter화면 바탕
  • 종이 --paper영수증, 입력칸
  • 잉크 --ink글자, 기본 버튼
  • 흐린 잉크 --ink-soft설명, 보조 글
  • 형광펜 --hl"나"에게만
  • 빨간 인주 --stamp-red초과, 오류, 항복 버튼
  • 회색 인주 --stamp-gray미확인, 항복, 봉인, 자동 제외
  • 파란 인주 --stamp-blue완주, 조정 완료
  • 메달 --gold --silver --bronze1 · 2 · 3등만
  • 사람 색 --p1 ~ --p6사람 토큰만 (참여 순서로)

예전 변수(--bg --text --muted --line --accent --danger)도 그대로 써요. 지금 화면 코드는 고치지 않아도 돼요.

글꼴

이번 주 예산, 누가 끝까지 버틸까?

69,000원 · 31% · D-4

Noto Sans KR 하나. 숫자도 같은 글꼴이고 .n 이 굵기와 자리 맞춤(tabular-nums)을 넣어요.

버튼

기본 버튼은 한 화면에 하나, 영수증 맨 아래. 나머지는 .secondary 나 글자 링크. 되돌릴 수 없는 일(항복)은 .danger-line 이고 확인 화면을 한 번 거쳐요.

입력칸과 계좌 고르기

예산은 1,000원 이상으로 넣어 주세요.

오류 칸에는 aria-invalid="true" 와 아래 .danger 한 줄. 계좌는 label.pick 카드로 은행 이름 + 가린 계좌번호(등록계좌조회 모양)를 보여 줘요.

.token .p1~.p6 은 닉네임 첫 글자 스티커(검은 테두리 + 각진 그림자). 색은 member_id 로 (id − 1) % 6 + 1. 나는 .is-me(형광 고리), 항복은 .is-quit(흑백), 빈자리는 .is-empty.

적용 방법

안정훈: static/common.css 를 static/board/common-proposal.css 내용으로 바꾸면 변수와 클래스 이름이 같아서 지금 화면은 그대로 동작해요. 흐름 화면 배치(단계 표시, 동의 표, 계좌 목록)는 static/board/flow/flow.css 에 있어요.

각자 화면: /flow 의 같은 화면을 보고, Claude Code 에 아래를 붙여 넣으면 돼요. 옮기는 법은 static/board/flow/README.md.

static/board/ui-guide.html, static/board/flow/README.md, static/common.css 를 읽고,
/flow 의 같은 화면을 기준으로 내 레인 화면을 맞춰 줘.
새 색이나 글꼴을 만들지 말고 가이드의 것(button, .secondary, .small, .danger-line, .note, .stamp, .tag,
.medal, .token, .lineup, .gauge, label.pick, .stepper, .consent, .n, mark, .is-me, ul.list, hr)만 써.
한 화면에 큰 글자 하나와 기본 버튼 하나, 형광펜은 "나"에게만, 설명 문장은 빼고, 말투는 해요체로 숫자 먼저.

화면에 적용하면

같은 스타일로 그린 예시예요. 닉네임과 금액은 예시 데이터예요. 이름을 누르면 실제로 눌러 보는 화면이 열려요.
