## 팀이 정한 것 🟢

- **입력**: 수기 + 지출내역 캡처(토스·카카오페이) 인식
- **공동계산**: 금액마다 "몇 명이서"만 선택한다. 금액 ÷ 인원만 내 지출로 잡는다
- **업로드 주기**: 방 규칙으로 설정한다. 기본은 주 1회
- **예산**: 각자 정하는 대로 넣는다
- **예산을 넘기면**: 탈락이 아니라 초과 표시 + 순위
- **마감까지 안 올리면**: 보드에 "미제출" 표시만
- **고정비(월세·통신비)**: 사용자가 "제외" 버튼으로 직접 뺀다

## 1. 문제 정의 🟡

- **누가**: 용돈·알바비로 한 달을 사는 대학생
- **언제 (막히는 순간)**: 월말이나 시험 기간에 돈이 떨어졌을 때
- **지금은 어떻게**: 혼자 가계부 앱을 쓰다 며칠 만에 그만두거나, 단톡방에 지출을 인증한다 (합계가 안 남음)
- **그 비용**: 다짐만 하고 실천으로 이어지지 않은 팀원 경험 (예: 일주일 예산 계획 = 학식 × 2 × 날짜)

## 2. 타깃 사용자 🟡

- 22세, 자취하는 3학년, 용돈 + 알바, 체크카드와 토스 사용

## 3. 솔루션 한 줄 🟡

- 친구들과 목표를 공유함으로써 달성 의욕을 높인다

## 4. 핵심기능 1개 🟡

- **입력**: 지출 (수기 또는 캡처) + 항목마다 "몇 명이서"
- **처리**: 캡처에서 지출내역을 읽고 카테고리(병원, 음식 등)를 붙인다. 금액 ÷ 인원을 내 지출로 더해 예산에서 뺀다
- **출력**: 방 멤버별 남은 예산 보드 + 순위
- **확장 기능**: 업로드 주기와 마감 규칙 · 결과 카드 공유 · 또래 평균 예산

## 5. 범위 밖 🟡

- 토스 계좌 연동
- 수익화 (배너 광고)
- 회원가입
- 앱 (웹만)
- 실제 돈 걸기 (내기·송금)
- 거래 항목을 친구에게 공개

## 6. 필요 데이터 🔴

| 데이터 | 출처 / API | 어디에 쓰나 | 확인 |
|---|---|---|---|
| 캡처 → 거래 목록 인식 | Claude API (이미지 입력, 인증키 필요, 유료) | 지출 입력 | 호출 전 |
| 방 · 멤버 · 지출 저장 | DB (종류 미정) | 남은 예산 보드 | 미정 |
| 테스트용 캡처 20~30장 | 팀원 토스·카카오페이 화면 | 인식 정확도 확인 | 수집 전 |

- 외부 공공 데이터는 필요 없다.
- 캡처에는 잔액 · 계좌번호 일부 · 송금 상대 이름이 찍힌다. 인식 후 버리고 저장하지 않는다.
- 캡처가 외부 API로 전송된다는 점을 업로드 화면에 알린다.
- 실제 캡처는 이 레포에 올리지 않는다 (공개 레포).

## 7. 성공 지표 🟡

후보 (핵심 1개와 baseline을 골라야 함):

- 10/1~10/7 1주 챌린지에서 5명 중 4명 이상이 마감일에 지출을 제출
- 목표 금액을 입력받고 목표 날짜까지 데이터가 유지된다 (DB)
- 캡처 한 장을 올리면 정확도 90% 이상의 결과가 10초 안에 표시된다
- 캡처 한 장을 올리면 카테고리 분류가 80% 이상 맞는다

baseline 후보: 사전 질문 "혼자 가계부를 1주 넘게 쓴 적 있나" 인원, 또는 단톡방 수동 챌린지 제출 인원. 10/8 전에는 1주만 잴 수 있다.

## 8. 기대 효과 🔴

- **사회적 임팩트**: 혼자서는 이어 가지 못하는 지출 관리를 친구와 함께라서 이어 간다
- **근거 (출처 URL)**: 아직 없음

## 사용 흐름

1. **방 만들기**: 기간 · 업로드 주기 · 마감 요일을 정하면 링크가 생긴다
2. **참여**: 링크를 열고 닉네임과 내 예산만 넣는다 (로그인 없음, when2meet 참고)
3. **지출 올리기**: 수기로 넣거나 토스·카카오페이 캡처를 올린다
4. **확인 화면**: 인식된 출금 목록에서 항목마다 "몇 명이서"를 고른다
5. **보드**: 멤버별 남은 예산 막대 · 순위 · 미제출 표시 · 마감 후 결과 카드

## 캡처 인식 규칙

- 출금만 읽고 입금은 무시한다. 정산받은 돈은 "몇 명이서" 선택으로 이미 처리된다
- 가승인 결제는 제외한다 (택시, 환불처럼 같은 출금처로 두 번 적히는 경우)
- 항목마다 "제외" 버튼을 둔다. 내 계좌 간 이체와 충전은 자동으로 제외 후보로 표시한다
- 기간 밖 날짜는 자동으로 제외한다. 날짜 · 상호 · 금액이 같으면 중복 경고를 띄운다
- 캡처는 인식 후 버린다. 친구에게는 합계와 남은 예산만 보인다

## 확인이 필요한 것

- **솔루션 한 줄의 형식**: 수업 기준은 "○○할 때 ○○를 알려준다"인데 지금 문장은 이 형식이 아니다
- **핵심기능의 범위**: 수기 입력, 캡처 인식, 카테고리, 순위가 한 항목에 모두 들어 있다. `BUILD_ORDER.md`에서는 수기 입력을 1라운드, 캡처 인식을 2라운드로 나눴다
- **순위 기준**: 예산이 각자 다르므로 금액이 아니라 사용률(쓴 돈 ÷ 예산)로 매기는 안을 제안한다
- **성공 지표**: 핵심 1개와 baseline을 골라야 한다
- **기술 스택과 DB**: `BUILD_ORDER.md`의 제안을 팀이 확인해야 한다
